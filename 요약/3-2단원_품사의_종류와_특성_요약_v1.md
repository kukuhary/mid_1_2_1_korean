## 2. 단어와 품사의 기본 개념

### 1) 단어(單語)
- 자립하여 홀로 쓰일 수 있는 말(자립 형태소).
- 단, 자립성은 없으나 자립할 수 있는 말(체언) 뒤에 붙어 **쉽게 분리될 수 있는 말(조사)**도 단어로 인정함.

### 2) 품사(品詞)
- 공통된 문법적 성질(형태, 기능, 의미)을 가진 것끼리 묶은 단어의 갈래.

### 3) 품사 분류의 3대 기준
1. **형태 (문장에서 쓰일 때 형태의 변화 여부)**:
   - **불변어**: 문장에서 쓰일 때 형태가 변하지 않는 단어 (체언, 수식언, 관계언, 독립언).
   - **가변어**: 문장에서 쓰일 때 형태가 변하는(활용하는) 단어 (용언: 동사, 형용사 / **[함정] 서술격 조사 '이다'**).
2. **기능 (문장 안에서 단어가 하는 역할 및 다른 말과의 문법적 관계)**:
   - **체언**(몸체 구실: 주어·목적어·보어 등) / **수식언**(꾸며 주는 구실) / **관계언**(문법적 관계 표시) / **독립언**(독립적 쓰임) / **용언**(서술하는 구실).
3. **의미 (단어가 지닌 고유한 의미 범주)**:
   - **9품사**: 명사, 대명사, 수사, 관형사, 부사, 조사, 감탄사, 동사, 형용사.

## 3. [인포그래픽 1] [빈출] 한 문장 9품사 올인원 완전체 상호작용 지도

> **"앗! 그가 새 옷 둘을 아주 예쁘게 입는다."**

```text
┌───────┬────────┬───────┬───────┬───────┬───────┬───────┬─────────┬─────────┬─────────┐
│  앗!  │   그   │  가   │  새   │  옷   │  둘   │  을   │  아주   │ 예쁘게  │ 입는다  │
├───────┼────────┼───────┼───────┼───────┼───────┼───────┼─────────┼─────────┼─────────┤
│[감탄사]│[대명사]│[조사] │[관형사]│[명사] │[수사] │[조사] │ [부사]  │[형용사] │ [동사]  │
│(독립언)│ (체언) │(관계언)│(수식언)│(체언) │(체언) │(관계언)│ (수식언)│ (용언)  │ (용언)  │
│(불변어)│(불변어)│(불변어)│(불변어)│(불변어)│(불변어)│(불변어)│ (불변어)│ (가변어)│ (가변어)│
└───────┴────────┴───────┴───────┴───────┴───────┴───────┴─────────┴─────────┴─────────┘
```

1. **`앗!` [감탄사] (독립언 / 불변어)**: 문장 맨 앞에서 다른 문장 성분에 얽매이지 않고 독립적으로 놀람의 감정을 표출함.
2. **`그` [대명사] (체언 / 불변어)**: 대상을 대신 가리키며 뒤에 주격 조사('가')가 결합함.
3. **`가` [조사] (관계언 / 불변어)**: 체언 뒤에 붙어 주어의 자격을 나타내는 주격 조사.
4. **`새` [관형사] (수식언 / 불변어)**: 오직 뒤의 체언(`옷`)만을 전문적으로 수식함 (조사 결합 절대 불가).
5. **`옷` [명사] (체언 / 불변어)**: 구체적인 사물의 명칭을 나타냄.
6. **`둘` [수사] (체언 / 불변어)**: 사물의 수량을 나타내며 목적격 조사(`을`)가 직접 결합함 (수사 판별의 결정적 근거).
7. **`을` [조사] (관계언 / 불변어)**: 체언 뒤에 붙어 목적어의 자격을 나타내는 목적격 조사.
8. **`아주` [부사] (수식언 / 불변어)**: 뒤에 오는 형용사(`예쁘게`)를 꾸며 주는 구실을 함.
9. **`예쁘게` [형용사] (용언 / 가변어)**: 대상의 상태나 성질을 풀이함 (기본형: 예쁘다).
10. **`입는다` [동사] (용언 / 가변어)**: 주어(`그가`)의 구체적인 움직임이나 동작을 서술하여 문장을 완성함 (기본형: 입다).

## 5. [인포그래픽 3] [함정] 동사 vs 형용사 초고속 판별 알고리즘 (순서도)

```text
                      [ 판별할 단어의 어간 (먹-, 예쁘-) ]
                                       │
                                       ▼
                       【 '-ㄴ다 / -는다' 결합 저울 】
                                       │
                    ┌──────────────────┴──────────────────┐
                    ▼                                     ▼
           [ 저울이 자연스럽게 통과 ]             [ 저울에서 삐걱거려 탈락 ]
           ========================               ========================
            • 밥을 먹 + 는다 ➔ 먹는다 (O)          • 얼굴이 예쁘 + ㄴ다 ➔ 예쁜다 (X)
            • 운동장을 달리 + ㄴ다 ➔ 달린다 (O)    • 하늘이 푸르 + ㄴ다 ➔ 푸른다 (X)
                    │                                     │
                    ▼                                     ▼
              【 동  사 】                          【 형 용 사 】
             (움직임/동작)                          (상태/성질)
                    ▲                                     ▲
                    │                                     │
          [명령·청유형 결합 가능]               [명령·청유형 결합 불가]
          (먹어라 O, 같이 먹자 O)               (푸르러라 X, 예쁘자 X)
```

### 판별 5대 체크리스트
1. **현재 시제 선어말 어미 `'-ㄴ다 / -는다'`**: 동사는 결합 가능(`읽는다`, `간다`), 형용사는 결합 불가(`조용한다 X`, `착한다 X`).
2. **명령형 어미 `'-아라 / -어라'`**: 동사는 결합 가능(`뛰어라`), 형용사는 결합 불가(`예뻐라 [명령] X` ➔ `예쁘게 가꾸어라 O`).
3. **청유형 어미 `'-자'`**: 동사는 결합 가능(`함께 가자`), 형용사는 결합 불가(`건강하자 X` ➔ `건강하게 지내자 O`).
4. **현재 진행형 `'-고 있다'`**: 동사는 결합 가능(`달리고 있다`), 형용사는 결합 불가(`푸르고 있다 X`).
5. **목적·의도 어미 `'-러 / -려'`**: 동사는 결합 가능(`놀러 가다`), 형용사는 결합 불가(`조용하러 가다 X`).

## 6. [인포그래픽 4] [함정] 실전 시험 단골 3대 문법 함정 정복 클리닉

| 함정 유형 | 핵심 판별 기준 및 설명 | 대표 예문 및 오류 교정 |
| :--- | :--- | :--- |
| **[함정 1]<br>수사 vs 수 관형사 구별** | • 뒤에 **조사가 결합할 수 있으면** ➔ **[수사]**<br>• 뒤의 명사를 수식하고 **조사가 결코 결합할 수 없으면** ➔ **[관형사]** | • "사과 **둘을** 먹었다." (수사 '둘' + 목적격 조사 '을')<br>• "사과 **두** 개를 먹었다." (명사 '개'를 꾸미는 관형사 '두') |
| **[함정 2]<br>관형사 뒤 조사 결합 오류** | • 관형사는 체언만 꾸미며 **조사가 결코 결합할 수 없음**.<br>• 조사를 붙이려면 체언(명사)으로 교체해야 함. | • (X) "**옛부터** 전해 내려온 마을 전설"<br>• (O) "**옛날부터** 전해 내려온 마을 전설" (명사 '옛날' + 조사 '부터') |
| **[함정 3]<br>형용사 청유·명령형 오류** | • 형용사는 상태를 나타내므로 **청유형('-자')이나 명령형 어미를 결코 쓸 수 없음**. | • (X) "항상 마음이 **예쁘자**."<br>• (O) "마음을 **예쁘게 가꾸자**." 또는 "**예뻐지자**."(동사화) |

## 7. [인포그래픽 5] [빈출] 담화 성격 및 연설문 속 품사의 전략적 활용 효과

### 1) 교과서 수록 대표 담화 분석
| 구분 | 그림책 《달 샤베트》(백희나) — 문학·감각적 담화 | 재난 안전 문자 — 실용·정보 전달 담화 |
| :--- | :--- | :--- |
| **주요 품사** | 의성어·의태어 **부사** 다채롭게 활용 (`아주아주`, `너무너무`, `꼭꼭`, `쌩쌩`, `똑똑`) | 수식언(관형사·부사) 최대한 배제, **명사 중심** 간결한 어휘 (`폭염 경보`, `야외 활동 자제`) |
| **표현 효과** | 장면의 소리와 움직임을 **생동감 있고 감각적으로 묘사**하여 독자의 상상력과 흥미 극대화 | 긴급한 정보를 **신속·정확하고 객관적이며 신뢰성 있게** 청자에게 직관적으로 전달 |

### 2) 창의 융합 활동 〈세상을 움직인 연설가〉 속 품사 전략
- **김구**: '독립', '민족' 등 핵심 **명사**를 거듭 반복하여 광복을 향한 단호한 의지 강조.
- **스티브 잡스**: '대단한', '놀랍다' 등 감정에 호소하는 **형용사**를 다수 활용하여 청중의 공감 유도.
- **말랄라 유사프자이**: '파괴되다', '막다' 등 역동적 **동사**와 핵심 **명사**를 결합하여 교육권 보장 촉구.
- **스파르시 샤**: '십오 년', '백삼십 번' 등 정확한 **수사**를 제시하여 장애 극복 의지의 진정성 확보.
