- **원천 자료**: 남서울중학교 1학년 1학기 국어 학습지 (2페이지 전면)
- **교과서 출처**: 2022 개정 미래엔 국어 1-1 대단원 3 - 소단원 (2) 품사의 종류와 특성 연계

- **조판 규격**: 100% 흑백(Monochrome) 벡터 조판, 정확한 2페이지 규격, 유니코드 이모지 배제

## 1. 개관: 왜 교과서 외 심화 문법을 공부해야 하는가?

2022 개정 미래엔 중1 국어 교과서 3-(2)단원은 9품사의 **기본 개념과 5대 기능(체언·수식언·독립언·관계언·용언), 그리고 동사/형용사 구별**까지만 다룹니다.
그러나 실제 학교 현장에서는 내신 변별력 확보를 위해 **학교 자체 학습지(프린트)를 통해 중2~중3 및 고등학교 수준의 9품사 세부 하위 분류**를 대거 출제합니다. 본 요약서는 교과서에는 전혀 나오지 않지만 학습지에 수록되어 시험에 킬러 문항으로 직결되는 핵심 심화 내용을 100% 압축 정리하였습니다.

## 2. [체언의 심화 분류] 명사 · 대명사 · 수사의 세부 갈래

### 1) 명사(名詞)의 3대 세부 분류 기준

| 분류 기준 | 세부 갈래 | 개념 정의 | 대표 예시 단어 |
| :--- | :--- | :--- | :--- |
| **① 구체성 유무** | **구체 명사** | 구체적인 모양이나 형체가 있는 대상의 이름을 나타냄 | 나무, 하늘, 집, 자동차, 책 |
| | **추상 명사** | 구체적 형체 없이 머릿속 생각이나 감정, 개념의 이름을 나타냄 | 우정, 행복, 노력, 희망, 사랑 |
| **② 사용 범위** | **고유 명사** | 특정한 사람, 지역, 기관 등 유일한 대상의 이름을 나타냄 | 이순신, 신사임당, 부산, 대한민국 |
| | **보통 명사** | 같은 특성을 지닌 대상에 두루 통용되어 쓰이는 이름을 나타냄 | 과일, 사람, 동물, 꽃, 학생 |
| **③ 자립성 유무**<br>*(★ 고난도 빈출)* | **자립 명사** | 다른 말의 도움 없이 문장에서 홀로 쓰일 수 있는 명사 | 어머니, 바다, 친구, 하늘 |
| | **의존 명사** | **반드시 앞말(관형어)의 꾸밈을 받아야만** 쓰일 수 있는 명사 | 먹을 **것**, 학생 한 **명**, 사과 두 **개**, 갈 **수** 있다 |

> **[함정 1] 의존 명사 판별 핵심 공식**:
> - 형태가 짧아서 조사나 접미사로 착각하기 쉽지만 엄연한 **체언(명사)**임.
> - 앞에 반드시 꾸며 주는 말(관형어)이 와야 하며, **앞말과 띄어 씀** (예: `먹을 V 것`, `한 V 개`).
> - 뒤에 조사가 자유롭게 붙을 수 있음 (예: `것이`, `것을`, `것이다`).

| :--- | :--- | :--- |

### 3) 수사(數詞)의 세부 분류

| 세부 갈래 | 개념 정의 | 대표 예시 단어 |
| :--- | :--- | :--- |
| **양수사 (量數詞)** | 사물의 **수량(개수, 양)**을 나타내는 수사 | 하나, 둘, 셋, 넷, 일, 이, 삼, 십 |

## 3. [관계언의 심화 분류] 조사의 3대 갈래 체계

교과서에서는 조사를 '문법적 관계 표시 및 특별한 뜻을 더하는 단어'로만 설명하지만, 학습지에서는 이를 **격조사 · 접속조사 · 보조사**의 3대 문법 체계로 엄격히 구분합니다.

| 조사의 종류 | 핵심 개념 정의 | 대표 조사 목록 | 실전 예문 |
| :--- | :--- | :--- | :--- |
| **격조사**<br>(문법적 자격 부여) | 체언 뒤에 붙어 그 말이 문장 안에서 **일정한 문법적 자격(문장 성분)**을 갖추도록 해 주는 조사 | • **주격 조사**: 이/가, 께서<br>• **목적격 조사**: 을/를<br>• **관형격 조사**: 의<br>• **부사격 조사**: 에, 에서, 에게, 로<br>• **서술격 조사**: -이다 *(가변어)* | • 비**가** 내린다. (주어)<br>• 밥**을** 먹는다. (목적어)<br>• 동생**의** 책 (관형어)<br>• 학교**에서** 공부한다. (부사어)<br>• 그는 학생**이다**. (서술어) |
| **접속조사**<br>(대등한 연결) | 두 단어를 대등한 자격으로 직접 이어 주는 조사 | **과/와, 하고, (이)랑** | • 사과**와** 배를 샀다.<br>• 너**하고** 나랑 가자. |
| **보조사**<br>(특별한 뜻 첨가)<br>*(★ 최고 빈출)* | 체언 등에 붙어 앞말에 **특별한 문법적 뜻(의미)을 덧붙여 주는** 조사 (문장 성분 자격 부여 X) | **은/는** (대조, 화제)<br>**도** (포함, 역시)<br>**만** (단독, 유일)<br>**마저 / 조차** (극한, 마지노선)<br>**부터 / 까지** (시작과 끝) | • 인생**은** 짧고 예술**은** 길다.<br>• 나**도** 그 영화를 보았다.<br>• 오직 너**만** 믿는다.<br>• 마지막 희망**마저** 사라졌다. |

> **[함정 2] 격조사 vs 보조사 구별 1초 판별법**:
> - 격조사는 문장 성분의 자격만 줄 뿐 고유한 뉘앙스를 더하지 않음 (`철수가 간다` = 단순 사실 서술).
> - 보조사는 특별한 뉘앙스(대조, 한정, 포함)를 덧붙임 (`철수는 간다` = 다른 사람은 안 가는데 철수는 감 / `철수도 간다` = 다른 사람도 가는데 철수 역시 감).
> - **'은/는'은 주격 조사가 아니라 [보조사]이다!** (중1 시험 1위 함정). 주격 조사는 오직 `이/가`, `께서`임.

## 4. [수식언의 심화 분류] 관형사 · 부사의 세부 갈래

### 1) 관형사(冠形詞)의 세부 분류

| 세부 갈래 | 개념 정의 | 대표 예시 단어 |
| :--- | :--- | :--- |
| **성상 관형사** | 대상의 **성질이나 상태**를 뚜렷하게 규정하며 체언을 꾸밈 | **새** 옷, **헌** 신발, **옛** 기억, **온갖** 꽃 |
| **지시 관형사** | 대상을 **가리키며(지시하며)** 체언을 꾸밈 | **이** 책, **그** 사람, **저** 건물, **무슨** 소리, **어느** 날 |
| **수 관형사** | 뒤에 오는 명사의 **수량이나 순서**를 꾸밈 *(조사 결합 절대 불가)* | **한** 명, **두** 개, **세** 사람, **첫째** 아들, **여러** 나라 |

---

### 2) 부사(副詞)의 세부 분류: 성분 부사 vs 문장 부사

부사는 문장에서 꾸며 주는 범위에 따라 **문장의 일부분만 꾸미는 '성분 부사'**와 **문장 전체를 통째로 꾸미는 '문장 부사'**로 나뉩니다.

| 상위 분류 | 하위 갈래 | 개념 정의 | 대표 예시 단어 및 문장 |
| :--- | :--- | :--- | :--- |
| **성분 부사**<br>(문장의 특정 성분을 수식) | **성상 부사** | 모양, 상태, 성질, 정도를 꾸밈 | 꽃이 **활짝** 피었다. 걸음이 **매우** 빠르다. **잘** 달린다. |
| | **지시 부사** | 장소, 시간, 앞선 사실을 가리키며 꾸밈 | **이리** 오너라. **그리** 멀지 않다. **오늘** 떠난다. |
| | **부정 부사** | 용언 바로 앞에서 동작이나 상태를 부정함 | 밥을 **못** 먹었다. 학교에 **안(아니)** 간다. |
| **문장 부사**<br>(문장 전체를 수식) | **양태 부사** | **말하는 이의 심리적 태도나 확신**을 문장 전체에 드러냄 | **설마** 그럴 리가? **과연** 듣던 대로군. **제발** 부탁해. **결코** 잊지 않겠다. |
| | **접속 부사** | 앞말과 뒷말, 앞 문장과 뒤 문장을 이어 줌 | 봄이 왔다. **그리고** 꽃이 피었다. 비가 온다. **그러나** 출발한다. |

## 5. [용언 · 독립언의 심화 분류] 동사 · 형용사 · 감탄사의 세부 갈래

### 1) 동사(動詞)의 세부 분류: 자동사 vs 타동사

| 세부 갈래 | 개념 정의 | 판별 기준 (목적어 유무) | 대표 예시 단어 |
| :--- | :--- | :--- | :--- |
| **자동사 (自動詞)** | 움직임이나 작용이 주어 자신에게만 미치는 동사 | **목적어(`을/를`)가 필요 없음** | 새가 **날다**, 꽃이 **피다**, 집에 **가다**, 바람이 **불다** |
| **타동사 (他動詞)** | 움직임이나 작용이 다른 대상(목적어)에 미치는 동사 | **반드시 목적어(`을/를`)를 필요로 함** | 옷을 **입는다**, 책을 **본다**, 물을 **마신다**, 밥을 **먹다** |

---

### 2) 형용사(形容詞)의 세부 분류

| 세부 갈래 | 개념 정의 | 대표 예시 단어 |
| :--- | :--- | :--- |
| **성상 형용사** | 대상의 **성질이나 상태**를 직접 나타내는 형용사 | 마음이 **착하다**, 방이 **넓다**, 눈이 **하얗다**, 물이 **맑다** |
| **지시 형용사** | 성질, 상태, 시간, 수량 등이 **이러하거나 저러하다는 것을 대신 나타냄** | 성격이 **이러하다**, 모양이 **그러하다**, 형편이 **어떠하다** |

---

### 3) 감탄사(感歎詞)의 세부 분류

| 세부 갈래 | 개념 정의 | 대표 예시 단어 |
| :--- | :--- | :--- |
| **놀람 · 느낌 감탄사** | 말하는 이의 본능적인 놀람, 감탄, 슬픔, 당황을 나타냄 | **앗**, **어머**, **아차**, **아이고**, **저런**, **어라** |
| **부름 감탄사** | 상대방을 부르거나 주의를 끌 때 사용함 | **야**, **얘**, **여보**, **여보게**, **여보세요**, **이봐** |
| **대답 감탄사** | 상대방의 부름이나 질문에 응답할 때 사용함 | **네**, **아니요**, **예**, **응**, **그래**, **오냐** |

## 6. [실전 킬러 문항 정복] 심화 3대 문법 판별 클리닉

### [클리닉 1] 수사 vs 수 관형사 완벽 판별
- **수사**: 체언이므로 **뒤에 조사가 결합할 수 있음** ➔ `"사과 **둘을** 먹었다."` (`둘` + 조사 `을` 결합 ➔ **양수사**)
- **수 관형사**: 수식언이므로 **조사 결합 불가, 뒤의 명사를 수식** ➔ `"사과 **두** 개를 먹었다."` (`두` 뒤에 조사 불가, 명사 `개` 수식 ➔ **수 관형사**)

### [클리닉 2] 자립 명사 vs 의존 명사 완벽 판별
- **자립 명사**: 문장 처음에 홀로 쓰일 수 있음 ➔ `"**친구**가 왔다."`
- **의존 명사**: 홀로 쓰이지 못하고 반드시 관형어의 꾸밈을 받아야 함 ➔ `"할 **수** 있다."`, `"아는 **것**이 힘이다."`, `"사과 세 **개**"`

### [클리닉 3] 자동사 vs 타동사 완벽 판별
- 문장에 목적격 조사(`을/를`)를 넣어서 말이 성립하는지 확인!
  - `하늘을 난다 (X)` ➔ 날다는 **자동사**
  - `책을 읽는다 (O)`, `밥을 먹는다 (O)` ➔ 읽다, 먹다는 **타동사**
